Claudemy

Privacy and data handling

Last updated 15 October 2026. Applies to the Claudemy Claude Code skill and plugin, version 0.2.0 and later.

Where it runs

Claudemy runs on your own machine inside Claude Code. It has no server of its own, no account, and no analytics. Nothing is stored outside your computer except where this page says so.

What it reads

  • The topic you type, and your reactions to the sample lesson, inside your Claude Code session.
  • Public web pages it finds through Claude Code's web search and fetch tools while researching the topic. Copies of those pages are saved in a local workspace folder for your own study and for the citation checker.

What it sends, and to whom

  • Claude. Your topic and the research pass through Claude Code the same way any Claude Code session does, under Anthropic's terms for your plan.
  • ElevenLabs, only if you choose it. If you set an ElevenLabs API key, the text of each lesson script is sent to ElevenLabs to render the two voices, under ElevenLabs' terms. Your key is read from the ELEVENLABS_API_KEY environment variable or the plugin's configuration prompt and is used for that call only. If you set no key, audio is rendered locally with macOS built-in voices and nothing leaves your machine for audio.

What it keeps

Lessons, cards, audio files, the playbook and the saved research pages are written to a workspace folder on your machine. Delete the folder to delete everything.

What it does not do

  • No telemetry, usage tracking or crash reporting.
  • No cookies, no sign-up, no email collection.
  • No sharing or selling of anything to anyone.

Open source

The code is MIT licensed and public at github.com/assafkip/claudemy. Every network call the scripts make is visible in skills/claudemy/scripts/.
